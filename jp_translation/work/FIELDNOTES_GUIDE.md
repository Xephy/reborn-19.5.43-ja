# フィールドノート 翻訳ガイド

Pokémon Reborn のポケギア内アプリ「フィールドノート」の本文。
各フィールド（戦闘フィールド効果）の仕様を1行ずつ箇条書きにしたもの。

## 入出力

- 入力: `jp_translation/work/batch/gfn/gfn_XXXX.tsv`
  タブ区切り3列 = `id`, `（空欄）`, `英文`
- 出力: `jp_translation/work/answers/gfn_XXXX.tsv`
  タブ区切り2列 = `id`（入力からコピー）, `日本語訳`

入力1行に対して出力1行。行を落とさない。順序も入力どおり。
英文を出力に書き戻さない。ファイル末尾に余計なタグを付けない。

## 1. マークアップは原文どおり

本文には表示用のタグが埋まっている。**種類・個数・順序を原文と完全に同じにする。**
タグの中身（`fieldUp` `green` `tts="and"` など）は英語のまま、1文字も変えない。

| タグ | 意味 |
|---|---|
| `<icon=fieldUp>` `<icon=fieldDown>` | 上昇／下降の矢印アイコン |
| `<icon=fieldChange>` | 「〜になる」の変化アイコン |
| `<icon=fieldPlus>` | 「かつ／さらに」のプラスアイコン |
| `<icon=typeFIRE>` など | タイプアイコン |
| `<icon=fieldBurn>` `<icon=fieldSleep>` など | 状態異常アイコン |
| `<c=green>…</c>` `<c=red>…</c>` `<c=orange>…</c>` | 文字色。**中身は訳す** |
| `<fs=28>` `<b>` | サイズ・太字 |

アイコンは文章の動詞や助詞の役割をしている。**アイコンの前後の語順は原文のまま**にすると
意味がずれない。

```
Grass moves <icon=fieldUp> <c=green>x1.5</c>
→ くさわざ <icon=fieldUp> <c=green>x1.5</c>
```

`. . .`（半角ピリオド3つ、間に半角スペース）で終わる行は「続きは詳細で読める」の印。
**末尾の ` . . .` はそのまま残す。**

## 2. 用語

わざ名・とくせい名・どうぐ名・タイプ名は**公式日本語名**。
`jp_translation/work/glossary.json` と `glossary_extra.json` を引く。

同じ内容を旧版の館内資料として訳したものが `jp_translation/work/src/map_0428.jsonl` に
ある（571行、全訳済み）。**言い回しに迷ったらここを grep して合わせる。** 例:

| 英語 | 確定訳 |
|---|---|
| Created by … | 〜で 発生 |
| Nature Power | しぜんのちから |
| Camouflage | ほごしょく |
| Secret Power | ひみつのちから |
| Grounded Pokémon | 地上のポケモン |
| Certain attacks / Certain moves | 一部のわざ |
| attacks / moves | わざ |
| Atk / Def / Sp.Atk / Sp.Def / Speed | こうげき／ぼうぎょ／とくこう／とくぼう／すばやさ |
| Accuracy | めいちゅう |
| Activates … | 〜が 発動 |
| immune | 無効 |
| turns | ターン |
| fails | 失敗 |
| removes / terminate | 消す |
| stage(s) | 段階 |

フィールド名の確定訳:
エレキフィールド, グラスフィールド, ミストフィールド, 暗黒クリスタルのどうくつ,
チェスボード, サーカステント, 燃えるフィールド, 沼地フィールド, 虹のフィールド,
腐食フィールド, 腐食ミストフィールド, 砂漠フィールド, 氷のフィールド, 岩場フィールド,
森林フィールド, 超高温フィールド, 工場フィールド, ショートフィールド, 荒野, 灰の浜辺,
水面, 水中, どうくつ, グリッチフィールド, クリスタルのどうくつ, 濁った水面, 山, 雪山,
聖なるフィールド, ミラーアリーナ, おとぎ話フィールド, りゅうのあな, 花畑フィールド,
星空アリーナ, 新世界, 反転フィールド, サイコフィールド

Reborn 独自の造語（`Amplifield Rock`, `Striker Moves`, `Chess Attacks` など）は
自然な日本語に訳す。チェスの駒（Knight, Rook, Bishop, Queen, Pawn）は
ナイト／ルーク／ビショップ／クイーン／ポーンとする。

## 3. 長さ

一覧は1件1行で折り返さない。**タグを除いた本文は18文字以内**、
アイコンが2つ以上ある行は16文字以内に収める。
体言止め・助詞の省略で詰めてよい（例:「威力1.5倍」「ねむり状態にならない」）。

語の区切りには**半角スペース**を使う（`map_0428.jsonl` と同じ書き方）。
全角スペース（U+3000）は使わない。

「詳細」（`...` で始まる長い行）は文章になるので、この字数制限は適用しない。
ただし冗長にはしない。

## 4. その他

- **常用漢字のみ。** 表外漢字は書き戻し側の `dejoyo.py` が一括処理するので手で直さない
- 感嘆符・疑問符は半角（`!` `?`）
- 数値・倍率（`x1.5` `x2` `50%` `8`）はそのまま
- カンマ区切りのわざ名リストは、公式名を `、` で区切る

## 検証は自分でやらない

常用漢字チェック・表記ゆれ・タグの個数照合は、書き戻し側のツールが機械的に処理して
報告する。**確認のためのコマンドを自分で実行しないこと**（`--dry-run`、`check_joyo.py`、
`wc -l`、`diff`、自作の監査スクリプトはすべて不要）。過去の作業でエージェントの消費の
大半がこの自己検証だった。

訳しながら気をつけるのは1点だけ: **タグを原文と同じ種類・個数・順序で残す。**
書き出したら次のバッチへ進んでよい。
