# Pokémon Reborn 日本語化 — ストーリー会話 翻訳ブリーフ（グループ1）

## あなたの仕事
指定された入力ファイル `jp_translation/work/g1batch/in_XXX.jsonl` の各行
`{"id": 123, "m": "map_0827", "en": "原文"}` を日本語に訳し、
`jp_translation/work/g1batch/out_XXX.json` に **`{"123": "訳文", "124": "訳文", ...}`** という
JSON辞書（キーは id を文字列にしたもの）で書き出す。**それ以外のファイルは絶対に作成・変更しない。**

- 入力の全 id を必ず出力に含める（1件も飛ばさない）。
- どうしても訳せない／訳す必要がない行（英数字の記号だけ等）は、その id を出力に含めず、
  最後の報告で「未訳 id: ...」と列挙する。推測で埋めない。
- `m` は元のマップファイル名。会話は同じ `m` 内で id 順に連続しているので、**前後の行を読んで文脈を掴んでから訳す**こと。

## 作品について
Pokémon Reborn は荒廃した都市「リボーンシティ」を舞台にした、シリアスで重い雰囲気のポケモン二次創作。
会話は口語的でスラングも多い。日本語も自然な口語にする（直訳調にしない）。

## 絶対厳守：制御コードとプレースホルダ
原文に含まれる以下は **位置・個数を完全に保持**すること。ずれるとゲームが実行時に落ちる。

| コード | 意味 | 扱い |
|---|---|---|
| `\PN` | プレイヤー名 | そのまま残す。日本語では「\PN」を人名として自然な位置に置く |
| `\n` | 改行 | 個数を維持 |
| `\v[123]` | 変数 | そのまま |
| `\G` | ゴールド表示ウィンドウ | そのまま（位置も原文と同じ先頭/末尾に） |
| `\wtnp[35]` `\wt[..]` `\.` `\|` `\!` `\^` `\>` `\<` | ウェイト等 | そのまま |
| `\c[3]` `\se[..]` | 色・効果音 | そのまま |
| `{1}` `{2}` | 差し込み | 個数・番号を一致させる |
| `\ch[...]` | 選択肢 | **中身も含めて原文のまま完全にコピー**（翻訳しない）。カンマの数が変わると選択肢がずれる |
| `\tts[...]` | 読み上げ用テキスト | 角括弧の**中身は翻訳する**。`\tts[` と `]` は残す |
| `<b>` `<i>` `<ar>` `<br>` `<c2=...>` | タグ | そのまま、個数維持 |

原文が `NAME: ` で始まる行（例 `JULIA: Hiya!`）は話者名。**`ジュリア: 〜` のように日本語名+`: ` に置き換える**（全角コロンではなく半角コロン+半角スペース。既訳 `ノエル: アンナ、なに?` に合わせる）。

## 表記ルール
1. **常用漢字のみ**使用（常用外は かな書き）。例:「嬉しい→うれしい」「綺麗→きれい」「喋る→しゃべる」「貰う→もらう」「呉れる→くれる」「凄い→すごい」「勿論→もちろん」「頑張る」は可。
2. 句読点は使わず、**読点の代わりに全角スペース（U+3000）**、文末の句点は基本省略（ポケモン公式風）。ただし詩的な独白などでは「。」を使ってもよい。既訳の雰囲気に合わせる。
   例: `そんなことして　タダで済むと思ってんのか?`
3. `?` `!` は**半角**を使う（既訳に準拠）。`!?` `?!` も半角。
4. 三点リーダは `……`（全角2つ）を基本にする。原文 `...` 単独行は `…………`。
5. 英字の固有名詞・地名・人名は下記の確定訳を使う。

## 用語の統一（他バッチとの整合のため必ずこれを使う）
- `Field Effect Read-Out NN` → `フィールド効果データNN`
- `PULSE Read-Out NN` → `PULSEデータNN`
- フィールド名は「〜フィールド」で音写: Mountain→マウンテンフィールド、Burning Field→バーニングフィールド、
  Swamp Field→スワンプフィールド、Murkwater Surface→マークウォーターサーフェス、
  Electric Terrain→エレキフィールド、Grassy Terrain→グラスフィールド、Misty Terrain→ミストフィールド、
  Psychic Terrain→サイコフィールド（後者4つは本家公式訳）
- バッジ名は音写+「バッジ」: Cinder Badge→シンダーバッジ など
- `LIGHTSHARD` → `ライトシャード`
- `Team Meteor` → `チームメテオ` / `PULSE` → `PULSE`（英字のまま）
- 通り・駅名は音写（例: Kingsbury Station→キングスベリー駅、Sunrise Street→サンライズ通り）
- 方角の略記 `N:` `S:` `NE:` `NW:` `SE:` `SW:` は `北:` `南:` `北東:` `北西:` `南東:` `南西:`
- `Corin` → `コリン` / `Rini`（ジュリアがフロリニアを呼ぶ愛称）→ `リニ`
- `Verdignite` → `ベルディグナイト` / `Bubblefoam` → `バブルフォーム`
- `Ultra Beast` → `ウルトラビースト` / `Pokédex` → `ポケモン図鑑` / `Pokéstar Studios` → `ポケウッド`
- `Anomaly` → `アノマリー` / `New World` → `新世界` / `Sanctuary` → `聖域`
- `Underroot` → `アンダールート` / `Subway Network` → `地下鉄道網` / `Rhodochrine` → `ロドクライン`
- `Aegir Cave` → `エーギルどうくつ` / `Ametrine Mountain` → `アメトリン山`
- 常用外漢字の回避例: 絆→きずな、瞑想→めいそう、失踪→姿を消した、噂→うわさ、安堵→安心、
  嬉しい→うれしい、綺麗→きれい、喋る→しゃべる、貰う→もらう、凄い→すごい、勿論→もちろん、
  誰→だれ(「誰」は常用漢字なので可)、呪い→のろい、掴む→つかむ、諦める→あきらめる

## 訳例（既訳・この雰囲気に合わせる）
```
"You think you can get away with that?"  → "そんなことして　タダで済むと思ってんのか?"      (ファーン)
"...Noob."                                → "……ザコが"                                    (ファーン)
"Cute AND talented~"                      → "カワイイうえに　才能まであるなんてね〜"        (カイン)
"Drown."                                  → "溺れなさい。"                                 (アマリア)
"Hehe... Failing again..."                → "えへへ……また　だめだったね……"               (シェリー)
"Hold your applause! You've yet to see the final act!" → "拍手は　まだ早くてよ! 最終幕は　これからですわ!" (セラ)
"...This feels empty."                    → "……なんも　残らねぇな"                        (ブレイク)
"I see, I see... You are at a highly advanced stage of metamorphosis already!"
   → "なるほど　なるほど……キミは　すでに　かなり進んだ　変態段階に　あるようだね!"        (ベネット)
```
壊れた／憑依された台詞（`STOP gETtING in MY wAY!` のような不規則な大文字小文字）は、
**全角カタカナの片言**で表現する: `ジャマヲ　スルナ!`

## 名前のない一般NPC
口調は文脈（子ども／老人／若者／店員など）から自然に判断してよい。

## 品質チェック（提出前に必ず自分で実行）
ゲームルート（このリポジトリの最上位）で:
```
python3 jp_translation/work/g1batch/verify.py XXX
```
（XXX は担当バッチ番号、例 `007`）
`placeholder mismatch 0` / `missing 0` / `non-joyo kanji: none` になるまで
`out_XXX.json` を直してから終了すること。
